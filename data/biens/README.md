# Biens : références internes

Chaque bien reçoit une référence interne **AB-NNNN** (AB = Avishay Benazra), attribuée dans l'ordre d'entrée et jamais réutilisée.
- `registre.json` : correspondance référence interne ↔ référence et agence partenaires, prochaine référence libre.
- `AB-NNNN.json` : fiche du bien (caractéristiques, prix et sa vérification, droits médias et tournage, restrictions).

Règles :
- Seule la référence interne sert dans le dépôt, les journaux, les noms de fichiers et les échanges avec Avishay.
- La référence partenaire (ex. SV2342 chez Solvilla) et le nom de la propriété restent internes : jamais à l'écran, dans une légende ni dans un nom de fichier publié.
- Le mot-clé DM d'une publication (ex. « GOLF ») renvoie à la référence interne dans la base des leads.
